# Rampa Radical

Jogo infantil de destruição de carros para celular: pegue velocidade, salte da rampa e destrua o carro nos obstáculos. 13 fases, 7 carros, 6 rampas. Feito com Three.js e cannon.js.

**Jogar:** https://alexmorassi.github.io/rampa-radical/

## Controles
- Toque no lado esquerdo/direito da tela para virar (no ar, gira o carro).
- Botão NITRO abre o foguete.
- Teclado: setas ou A/D, espaço = nitro, P = pausa, R = reinicia.
